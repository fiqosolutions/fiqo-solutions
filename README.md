# FIQO Solutions — GitHub Pages Website

A responsive, static website for FIQO Solutions. It can be hosted free with GitHub Pages.

## Before publishing
1. Open `index.html`.
2. Replace `+91 967778 82898` with the real WhatsApp/phone number.
3. Replace `hellofiqo@gmail.com` with the real business email.
4. Update the FormSubmit email in the form action to the same real email.
5. Replace any service descriptions or locations you want to change.

## GitHub Pages
1. Create a GitHub repository, for example `fiqosolutions.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Your site will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Notes
- No server or database is required.
- The website is mobile responsive.
- The contact form uses FormSubmit; the first submission may require email confirmation.
- For production SEO, add your real domain, Google Search Console, sitemap.xml and robots.txt.
